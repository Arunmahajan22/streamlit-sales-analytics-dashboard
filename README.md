# 📊 Sales Performance Dashboard

An interactive Sales Analytics Dashboard built using **Streamlit, Pandas, and Plotly**.  
This project provides dynamic business insights through KPI metrics, multi-level filtering, and modern visualizations.

---

## 🚀 Project Overview

The Sales Performance Dashboard allows users to:

- Filter sales data by **Category**
- Filter by **Region**
- Select a **Date Range**
- View real-time KPI metrics
- Analyze product-wise sales
- Track time-based sales trends
- Visualize category contribution
- Download filtered data as CSV

This project demonstrates practical data analysis, visualization, and dashboard development skills.

## ⚙️ Installation & Setup

### 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/sales-performance-dashboard.git
```

### 2️⃣ Navigate to Project Folder

```bash
cd sales-performance-dashboard
```

### 3️⃣ Install Required Libraries

```bash
pip install -r requirements.txt
```

### 4️⃣ Run the Application

```bash
python -m streamlit run app.py
```

The dashboard will open in your browser at:

```
http://localhost:8501
```
